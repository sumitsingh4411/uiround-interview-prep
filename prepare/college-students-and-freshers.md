# Frontend interview preparation for college students and freshers

A plan for college students, interns and freshers who want a frontend developer job, from any college: tier-1, tier-2 or tier-3, on campus or off campus. What each round asks, what to learn in which year, the projects that get a resume shortlisted, and free questions to practise with tests on [UIRound](https://uiround.com).

## Who this is for

- Students in any year of B.Tech, BE, BCA, MCA or B.Sc who want a frontend, UI or web developer role.
- Freshers (0 to 1 year) applying for frontend internships, campus placements or their first SDE-1 job.
- Anyone from a non-CS branch moving into frontend. The [non-CS to frontend developer guide](https://uiround.com/guides/non-cs-to-frontend-developer) covers that path.

## The rounds you will face

Fresher and internship loops are shorter than senior ones, but the same four skills come up again and again:

| Round | What it checks | How to practise |
| --- | --- | --- |
| Online test | Aptitude, and one or two coding problems on arrays, strings and hash maps | Easy problems in JavaScript, timed |
| JavaScript and web basics | Closures, `this`, hoisting, the event loop, promises; HTML semantics, CSS layout, the DOM | Explain each concept out loud, then use it in code |
| Machine coding | Build a small working UI in 45 to 90 minutes: a todo list, tabs, a modal, a star rating | Build against tests, with a timer |
| HR or hiring manager | Your projects, why frontend, how you learn | Two project stories you can tell in two minutes |

Service companies such as TCS, Infosys and Wipro usually add aptitude and verbal sections; product companies and startups lean on machine coding. The [campus placement guide](https://uiround.com/guides/frontend-campus-placement-preparation) covers placement season semester by semester, and the [internship interview guide](https://uiround.com/guides/frontend-internship-interview) covers internship rounds.

## What to learn year by year

| Year | Focus | Goal by the end of the year |
| --- | --- | --- |
| First | HTML, CSS and JavaScript without a framework; Git | A portfolio page and one small app, deployed |
| Second | JavaScript in depth (closures, promises, the event loop), then React | Two projects in React, deployed, with READMEs; apply for internships |
| Third | Machine coding, easy and medium DSA in JavaScript, one deeper project | An internship, and a project you can explain in depth |
| Final | Timed practice: machine coding, JavaScript output questions, mock interviews | Placement or off-campus offers |

Starting late is fine. In the final year, spend most of your time on machine coding and JavaScript fundamentals, because those rounds decide most fresher frontend interviews.

## From a tier-2 or tier-3 college

The interview is the same for everyone; getting the interview is the hard part. What works:

- **Projects that prove skill.** A deployed project with one hard part done well (search that never shows stale results, a list that stays fast with thousands of rows) says more than a college name.
- **Referrals.** Most off-campus interviews start with a referral. Ask engineers whose work you can talk about specifically. See [how to get a referral for a frontend job](https://uiround.com/guides/how-to-get-a-referral-for-a-frontend-job).
- **Off-campus applications, consistently.** Careers pages, job boards and startup hiring posts, every week, with a resume tuned to frontend. The [off-campus guide](https://uiround.com/guides/off-campus-frontend-jobs-without-iit) has the full route.
- **A long-term plan.** For a four-year plan from a tier-3 college to big-tech frontend roles, read the [tier-3 college to FAANG roadmap](https://uiround.com/faang-roadmap).

## FAQ

<details>
<summary><b>Can I get a frontend job from a tier-3 college?</b></summary>

Yes. Frontend interviews test what you can build and explain, and that can be shown with projects, open-source work and a strong machine coding round. The extra work is in getting interviews: referrals and off-campus applications instead of campus placements.

</details>

<details>
<summary><b>Do freshers need DSA for frontend roles?</b></summary>

Usually some: easy and medium problems on arrays, strings, hash maps and stacks, often in the online test. Big-tech companies ask more. The [DSA for frontend interviews guide](https://uiround.com/guides/dsa-for-frontend-interviews) explains how much.

</details>

<details>
<summary><b>Should I learn React before JavaScript?</b></summary>

No. Interviewers ask JavaScript fundamentals first, and React makes sense only once closures, promises and the DOM do. Learn JavaScript properly, then React.

</details>
